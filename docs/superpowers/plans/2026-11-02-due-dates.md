# Due dates and overdue loans — plan

> **For agentic workers:** use `superpowers:executing-plans` to execute this plan task by task. Each step uses the checkbox (`- [ ]`) syntax.

**Goal:** each loan gets a due date at borrow time, the API lists the overdue loans, and the loans screen shows them.

**Spec:** [`docs/superpowers/specs/2026-11-02-due-dates-design.md`](../specs/2026-11-02-due-dates-design.md)

**Architecture:** a new module `backend/src/loans/due-date.ts` holds the loan duration and the date rules. `LoansService` uses it to write the due date and to find the overdue loans. `backend/src/db/migrate.ts` adds the column to a database that `main` created. The loans screen reads a new API function.

**Checks for each task:** `npm test` and `npm run lint` are green before the commit. The last task also runs `npm run test:coverage` and `npm run lint:doc`.

---

### Task 2: Add due dates to the loans of an existing database

**Files:**

- Create: `backend/src/db/migrate.ts`, `backend/src/db/migrate.spec.ts`
- Modify: `backend/src/db/database.ts`, `backend/CLAUDE.md`

**Interface:**

```ts
export async function migrateDatabase(client: Client): Promise<void>;
```

`createDatabase` calls it after `CREATE_TABLES_SQL` and before the seed.

- [ ] **Step 1:** write the failing tests. The tests create a file database with the SQL of `main`: the `loans` table has no `due_date` column. It has one open loan and one returned loan. The tests then call `createDatabase` on the same file. The last test adds a loan whose `borrowed_at` is not a date.

```ts
it('gives a due date to each loan of a database that main created', async () => {
  const database = await createDatabase(await createMainDatabase());
  const storedLoans = await database.select().from(loans);
  expect(storedLoans.map((loan) => loan.dueDate)).toEqual(['2026-10-15', '2026-10-20']);
});

it('keeps the loans when it opens a migrated database again', async () => {
  const url = await createMainDatabase();
  await createDatabase(url);
  const database = await createDatabase(url);
  expect(await database.select().from(loans)).toHaveLength(2);
});

it('fails and leaves the database unchanged when a loan gets no due date', async () => {
  const url = await createDatabaseFile(MAIN_CREATE_TABLES_SQL + UNPARSABLE_LOAN_SQL);
  await expect(createDatabase(url)).rejects.toThrow('1 loan(s) have no due date');
  expect(await hasDueDateColumn(url)).toBe(false);
});
```

- [ ] **Step 2:** run `npm test`. The tests fail with `no such column: due_date`.
- [ ] **Step 3:** write `migrateDatabase`. When `PRAGMA table_info(loans)` has no `due_date`, open a write transaction. In it: `ALTER TABLE loans ADD COLUMN due_date TEXT`, then `UPDATE loans SET due_date = date(borrowed_at, '+14 days')`. Build the `'+14 days'` text from `LOAN_DURATION_DAYS`. Then count the loans whose `due_date` is null. When the count is not 0, throw `Migration failed: <n> loan(s) have no due date`: the transaction closes without a commit, so it rolls back and the database stays unchanged. Else commit the transaction.
- [ ] **Step 4:** run `npm test`. The tests pass.
- [ ] **Step 5:** add to `backend/CLAUDE.md`: a change to an existing table → a step in `src/db/migrate.ts`, with a test on a database of the previous schema.
- [ ] **Step 6:** commit `feat(db): Add due dates to the loans of an existing database`.

### Task 3: List the overdue loans

**Files:**

- Modify: `backend/src/loans/loans.service.ts`, `backend/src/loans/loans.controller.ts`, `backend/src/loans/loans.service.spec.ts`, `backend/src/app.module.spec.ts`

**Interface:** `LoansService.listOverdue(): Promise<Loan[]>` and `GET /api/loans/overdue` → `Loan[]`.

- [ ] **Step 1:** write the failing tests. Each test borrows a book, then sets the due date of the loan with the database.

```ts
it('lists a loan whose due date was yesterday', async () => {
  const loan = await borrowWithDueDate(yesterday);
  expect((await loansService.listOverdue()).map((item) => item.id)).toEqual([loan.id]);
});

it('does not list a loan on its due date', async () => {
  await borrowWithDueDate(today);
  expect(await loansService.listOverdue()).toEqual([]);
});

it('does not list a returned loan', async () => {
  const loan = await borrowWithDueDate(yesterday);
  await loansService.returnLoan(loan.id);
  expect(await loansService.listOverdue()).toEqual([]);
});
```

The HTTP test in `app.module.spec.ts` borrows a book with `POST /loans`, then sets the due date of the loan to `2026-01-01` with the database of the app. It calls `GET /loans/overdue` and expects status 200 and a list with only that loan, with its new due date.

- [ ] **Step 2:** run `npm test`. The tests fail: `listOverdue` does not exist, and the route answers 404.
- [ ] **Step 3:** write `listOverdue`: `returnedAt` is `null` and `dueDate` is before `toDateOnly(new Date())`, ordered by `dueDate`. Add `@Get('overdue')` to the controller.
- [ ] **Step 4:** run `npm test`. The tests pass.
